# API Request Demo

This React application uses Vite. Install Node.js and npm, then run these
commands from `ApiRequestDemo`:

```sh
npm ci
npm start
```

Open the local URL printed by Vite. To build and preview the production output:

```sh
npm run build
npm run preview
```

The production files are written to `dist`.

Use npm and commit `package-lock.json` when updating dependencies. Keep it as the
only lockfile: npm can rewrite a coexisting Yarn lockfile into a format that
Dependabot cannot parse.
